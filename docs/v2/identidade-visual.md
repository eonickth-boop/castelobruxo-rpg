# Castelobruxo RPG V2 — Identidade visual

## Decisão oficial

- Direção: Arquivo Vivo
- Intensidade: Equilibrada
- Status: aprovada

## Objetivo

Criar uma interface com aparência de arquivo acadêmico mágico, antiga e sofisticada, sem prejudicar a clareza, a leitura e o uso diário.

## Princípios

1. Papel artesanal e madeira escura aparecem como materiais de apoio, não como excesso de textura.
2. Selos, fichas, brasões e detalhes botânicos são usados como pontos de identidade.
3. A organização visual deve continuar limpa, responsiva e fácil de navegar.
4. Ornamentos não podem competir com o conteúdo.
5. Formulários, menus e cards devem parecer parte do mesmo sistema acadêmico.

## Equilíbrio visual

- 70% estrutura limpa e legível
- 20% materiais e texturas discretas
- 10% ornamentos mágicos e institucionais

## Base cromática inicial

- Verde floresta escuro
- Marrom de madeira
- Creme de papel
- Dourado envelhecido
- Terracota discreta para alertas e destaques

## Próxima etapa

Construir o sistema visual definitivo com tipografia, cores, espaçamentos, botões, campos, cards, navegação, avisos e estados de interação.
